# Process standards (index)

The standing rules of an unattended zone run are the skill **`world-standards`** (`.claude/skills/world-standards/SKILL.md`):
taste and decisions, order and gates, agents and briefs, evidence, files and installs, and which task skill each job
loads. How a zone is run (phases, budgets, reviewer, install queue, ledger): `docs/zone-creation.md` (skill
`zone-creator`). The order is a command: `zonegen status <world> --project <p> --zone <z> --next`.
Reviewer checklist: `review-rubric.md`. What is not encoded yet: `README.md`.
